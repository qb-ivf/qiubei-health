# 第三方静态资源说明

## Material Symbols Outlined 子集

- 上游：Google Material Symbols
- 用途：患者端、医生端小程序图标字体
- 字体范围：仓库实际使用的 65 个图标，包含 `FILL` 0..1 轴
- 固定文件：`material-symbols-outlined-subset.woff2`
- SHA-256：`1912ddef81b71dc91739c657f39a4bfbc62c53213d1b5de94a91da7ce2a99392`
- 许可证：Apache License 2.0，全文见 `LICENSE.material-symbols.txt`
- 生成日期：2026-07-26

该文件是通过 Google Fonts CSS API 的 `icon_names` 参数生成的固定子集。更新图标时必须重新生成
子集、更新摘要和小程序 URL 的版本参数，不得改回第三方 CDN 运行时依赖。
