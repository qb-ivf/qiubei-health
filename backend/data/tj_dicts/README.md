# 天津监管字典与对照材料（S0 T6 / S2 数据补录用）

## 目录内容

| 文件 | 来源/用途 |
| :-- | :-- |
| `国家临床版2.0疾病诊断编码（ICD-10）.xlsx` / 中医版 | ICD-10 导入源（`python -m scripts.import_icd10` 直接读取） |
| `诊疗科目字典3.1.csv` | 规范 3.1 全量转录——填医生 `subjectCode/subjectName` 时查 |
| `科室类别字典3.2.csv` | 规范 3.2 全量转录——填 `deptID`（科室大类）时查 |

| `对照模板-医生诊疗科目.csv` | **发给医务**：每位在册医生填一行，交回后由运营在 admin"医生资质终审→编辑"逐个录入 |
| `对照模板-药品监管编码.csv` | **发给药房**：每个在售药品填一行，交回后在 admin"药品字典→编辑"录入（保存即自动触发目录上报） |

## 填写注意

1. **医生身份证号不要写进对照表**——单独收集后由运营直接在 admin 后台录入（加密存储、不回显）。
2. 科室类别编码取**大类**：如"呼吸内科"医生 → `deptID=03`（内科），具体科室名仍用"呼吸内科"。
3. 国家药品编码（countrydrcode）在药品说明书条形码/医保药品编码库可查；确实查不到的先留空（规范该字段非必输），补齐 drugClass/包装/产地即可先行备案。
4. CSV 用 Excel 打开若出现乱码：数据 → 自文本导入，编码选 UTF-8；或用 WPS 打开。

## 录入完成的验收

admin 后台"医生资质终审"与"药品字典"列表中，"监管备案"列全部显示**已补录**即完成
（对应 tianjin_supervision_s0_checklist.md T6 验收项）。
